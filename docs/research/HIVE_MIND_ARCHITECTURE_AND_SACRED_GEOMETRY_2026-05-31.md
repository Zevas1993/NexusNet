## Part A - The AI Hive Mind architecture (as actually designed)

### A1. Fractal nested-brain hierarchy (PB-018, canon book C02M0022/C01M0108)
NexusNet is a literal nested-brain topology, NOT a flat orchestrator:

```
NexusBrain (primary "mother" brain - largest instance, final cognition authority)
  |- hosts: MoE Cortex/Router, multi-plane memory, CritiqueAO, SelfTrainingAO, dreaming director
  |
  +-- Orchestrator (O) nodes  : carry a smaller NexusNet-style brain (broad task decomposition)
       +-- Assistant Orchestrator (AO) nodes : smaller brain than O (assistant-orchestration domain)
            +-- Expert nodes  : each is its own Mini-NexusNet "sub-brain"
                 |- its own input/hidden/output layers (a real subnetwork, not a prompt wrapper)
                 |- its own domain, tools, memory plane scope, evals, and local improvement loop
                 |- its own local training loop (runs in parallel under the mother brain's schedule)
```

Key canon rules:
- **Scale/responsibility gradient, not isolation.** brain_scale in {primary, orchestrator,
  assistant_orchestrator, expert, generated_candidate}. Every brain exposes parent_brain_ref,
  child_brain_refs, health_signal_refs, recovery_route_refs (substrate spec 4.7/5.1).
- **One shared substrate.** All brains operate on the same Neural Bus + HiveBlackboard + memory
  planes + dreaming protocol + immune/governance plane. Sparse activation controls *compute*, not
  *connectivity* (PB-017).
- **Self-healing continuity.** If any O/AO/expert/tool/plane begins to fail, peers and parents see
  it through traces, route around it, start repair/dream/eval, and keep unrelated work moving.

### A2. The mother brain (NexusBrain) internals (canon book Aspect 2/3, C02M0023)
- **Cortex "Dream Director"** at the same level as the router: global coordination, attends over
  expert *summaries* (not full hidden states), directs recursive dreaming, consolidates outputs.
- **MoE Router**: sparse expert activation (Mixtral-style top-k). Mother brain hosts the gating
  network; SelfTrainingAO monitors gating accuracy/perplexity and triggers router self-training.
- **Multi-plane memory** (Aspect 5): MemoryNode is a multi-tuple across planes
  [conceptual Hc, temporal Ht, emotional He, procedural Hp, imaginal Hi, social Hs, ethical Hv,
  metacognitive Hm, goal Hg, spatial Hsp, predictive Hpr] - plane-specific embeddings + a hypergraph
  of cross-plane relations + cross-plane message passing.
- **CritiqueAO / Meta Reasoner**: arbitration, consequence feedback, self-review before promotion.

### A3. The mini brain (per-expert Mini-NexusNet) internals (C02M0023, C01M0062)
Each expert is a self-similar smaller NexusNet:
- own subnetwork (input/hidden/output), own LoRA/adapter, own local memory scope, own eval suite,
  own local improvement loop; communicates only via the Neural Bus sparse message contract:
  `(summary_embedding, uncertainty_score, request_for_help_flag, token_ids)` (C01M0068).
- generated by combining parents / dreaming (PB-017); temporary + shadow-scoped on first use (PB-019);
  becomes permanent only after retention review; a parent retires only after Ivy-grade outperformance
  review (PB-020), and is archived (rollback-restorable), never deleted.

### A4. Neuroplasticity fabric (PB-017)
Self-improvement is hive-wide, not owned by one lane. Any node can, via typed contracts, observe hive
state, request research/dreaming/critique/sandbox/eval, propose improvements to itself or others, or
participate in expert generation. Recursive Neural Dreaming is a distributed protocol: high-temp
dreamer -> low-temp reviewer -> critic/consequence/eval/sandbox -> governance gate.

### A5. Mapping to the kernel already built
The `HiveTensorKernel` (real softmax attention, top-k / DeepSeek loss-free routing, GeGLU/SwiGLU
experts, RMSNorm residual, RoPE/harmonic positions, hazard exit) computes ONE brain instance's
forward pass. The fractal design means the SAME kernel is applied at every brain_scale - mother brain
over experts, an O over its AOs, an expert mini-brain over its skills. That recursion (parameter-shared
block reused at each scale) is exactly Ouro-style looped reuse, and is the modular way to realize the
nested hierarchy without separate code per level.

## Part B - Sacred geometry: shapes per plane/field (computable, not decorative)

The golden ratio is one element of a larger sacred-geometry basis. Different shapes fit different
planes because each shape has distinct *computable* structure (vertex/edge/face counts, symmetry,
dual, flow topology). Each mapping below gives the shape, its classical correspondence, and the REAL
math + invariant it contributes - so "sacred geometry" becomes testable structure, not aesthetics.

### B1. The five Platonic solids (element + computable structure)
Euler invariant for all: `V - E + F = 2`. Duals pair planes. Icosa/dodeca coordinates use PHI (already
in the substrate) - the golden ratio literally builds these shapes.

| Solid | Element | V,E,F | Dual | NexusNet plane affinity | Computable contribution |
| --- | --- | --- | --- | --- | --- |
| Tetrahedron | Fire | 4,6,4 | self | action/output (decisive, minimal, self-dual) | smallest stable simplex; 4-point basis |
| Hexahedron (cube) | Earth | 8,12,6 | octahedron | memory/engram (stable, grid storage) | axis-aligned lattice; 8-corner addressing |
| Octahedron | Air | 6,12,8 | cube | attention/routing (balance, 6 axes) | 3 orthogonal axes; dual of memory cube |
| Icosahedron | Water | 12,30,20 | dodeca | neural-bus message-passing (flow, 12 nodes) | PHI-coordinate vertices; max symmetry |
| Dodecahedron | Aether/Spirit | 20,30,12 | icosa | cortex/meta (integration, 12 pentagon faces) | PHI-faces; dual of the flow shape |

Use: each plane carries a `geometry_signature` = {solid, element, V, E, F, euler=V-E+F, dual}. The
Euler check (==2) is a real invariant; the dual relation links paired planes (memory<->attention,
flow<->cortex) as actual routing affinities.

### B2. Field/flow shapes (beyond the solids)
- **Torus (toroid)** - "infinite flow, cyclical creation". Fits the recurrent-deliberation loop and the
  federated-prior circulation. Computable: a point on a torus is
  `(R + r cos v) cos u, (R + r cos v) sin u, r sin v` with major/minor radii R,r. Invariant: the loop
  returns to start at u=2pi (periodicity) - a real check for the recurrent cadence.
- **Vesica Piscis** - intersection of two equal circles (centers one radius apart). "Union of
  complementary forces / portal". Fits cross-plane fusion and parent->child genome overlap. Computable:
  the lens width/height ratio is `sqrt(3)` exactly; overlap area `= 2r^2(pi/3 - sqrt(3)/4)`. Real ratio
  invariant `sqrt(3)` for any radius.
- **Golden spiral / phyllotaxis** - already in use via the golden angle (137.5deg). Fits positional
  encoding (max non-repeating spread). Already implemented as `rotary_pair` + harmonic PE.

### B3. Composite figures (whole-substrate scaffolds)
- **Flower of Life / Fruit of Life** - 13 evenly spaced circles; the generative grid. Fits the
  HiveBlackboard node layout (13-circle Fruit-of-Life lattice = a deterministic node placement that is
  symmetric and addressable). Computable: 13 centers on a hex-packed lattice; pairwise distances are
  exact multiples of r.
- **Metatron's Cube** - connect all 13 Fruit-of-Life centers; the lattice *contains all five Platonic
  solids*. Fits the full plane-adjacency map: one figure from which every plane's solid is derived,
  giving a single deterministic source for the plane geometry signatures. Computable: 13 points, all
  78 connecting lines (C(13,2)); the five solids appear as specific vertex subsets.
- **Sri Yantra** - 9 interlocking triangles -> 43 smaller triangles; "cosmic order / balance of
  complementary forces". Fits the governance/immune balance field (opposing forces held in proportion).
  Computable: 9 triangles, 43 sub-triangles, central bindu - exact counts as an invariant.

### B4. Harmonic frequency basis (already partly done, extend)
Harmonic intervals (unison..octave: 1/1, 6/5, 5/4, 4/3, 3/2, 2/1) are real frequency ratios. Map them
to plane cadence (already in `_loop_harmonic_cadence`) and to the 12-tone field for the 12-node flow
shapes (icosahedron 12 vertices <-> 12 semitones <-> Fibonacci indexing). Each ratio is exact rational
math; the octave (2:1) closes the cycle - a real periodicity invariant.

# Whole Brain Emulation Boundary Spec

Status: P2 online assimilation target. Research-only and boundary-setting. Do not market as consciousness uploading.

## Finding

Whole-brain emulation research is a roadmap of unresolved technical requirements: scanning, image interpretation, parameter estimation, neural simulation, body/environment simulation, and success criteria. There is no verified path today for uploading human consciousness. The useful NexusNet target is the discipline of emulation levels and success criteria.

## NexusNet Assimilation Target

Create a strict "emulation boundary" for any NexusNet brain-inspired claim. If NexusNet borrows from brain emulation, it must state which level is being emulated: structure, dynamics, learning rule, behavior, memory process, or subjective-consciousness theory. The last category stays out of product claims.

## Proposed NexusNet Components

- `EmulationLevel`: structural analogy, dynamic simulation, behavioral mimicry, developmental process, or consciousness claim.
- `SuccessCriteriaMatrix`: what would count as evidence at each emulation level.
- `ParameterGapLedger`: unknown parameters that prevent stronger emulation claims.
- `EmbodimentRequirement`: body, environment, sensor, action, and feedback needed for a behavior claim.
- `NoUploadClaimPolicy`: blocks unsupported language about consciousness transfer or human uploading.

## Promotion Gates

- Require explicit level and evidence for every brain-emulation reference.
- Mark consciousness-uploading as unsupported unless future peer-reviewed evidence changes the state of the field.
- Separate simulation success from identity or subjective continuity claims.
- Prefer small, testable circuit emulation targets.
- Keep ethics and privacy review mandatory for human-derived brain data references.

## Risks

- "Uploading consciousness" language can contaminate credible research artifacts.
- Whole-brain emulation is vastly harder than static connectomics.
- Philosophical identity questions cannot be resolved by engineering tests alone.

## Finding

Ancient and medieval memory arts used spatial structure, vivid association, ordered traversal, and deliberate placement to make knowledge retrievable. The useful NexusNet transfer is a spatial memory palace for KAC: not a flat vector store, but a navigable cognitive architecture with rooms, routes, anchors, and recall rituals.

## NexusNet Assimilation Target

Create a spatial KAC layer where memories are placed into conceptual locations. Retrieval becomes a traversal through rooms, shelves, evidence anchors, contradictions, and lineage paths rather than only nearest-neighbor search.

## Proposed NexusNet Components

- `MemoryPalaceMap`: conceptual rooms for domains, projects, users, skills, artifacts, and unresolved questions.
- `LocusAnchor`: stable location for a memory item with source links and privacy class.
- `RecallRoute`: ordered traversal path that reconstructs context for a task.
- `VividAssociationTag`: human-readable cue, image, phrase, or relation used for recall.
- `PalaceDecayAndRepair`: detects stale rooms, duplicate anchors, and broken source links.

## Promotion Gates

- Treat historical memory arts as cognitive design inspiration, not supernatural evidence.
- Keep every memory anchored to source evidence.
- Test palace retrieval against ordinary search and graph retrieval.
- Preserve privacy classes during traversal.
- Avoid decorative spatial UI unless it improves recall or review.

## Risks

- Spatial metaphors can become UI clutter.
- Vivid associations can bias recall if not grounded.
- Historical claims need careful source status and should not be promoted as science.

## Finding

Consciousness science is unsettled. Global neuronal workspace emphasizes global broadcast of selected information, while IIT emphasizes integrated causal structure. The practical NexusNet transfer is access control over what becomes globally available to the system, not a claim that global broadcast equals consciousness.

## NexusNet Assimilation Target

Create a global workspace router for NexusNet that decides which local signals become globally visible: goals, anomalies, memory candidates, tool results, contradiction alerts, operator commands, and self-evaluation failures.

## Proposed NexusNet Components

- `WorkspaceCandidate`: local signal nominated for global broadcast.
- `BroadcastGate`: salience, novelty, risk, contradiction, operator priority, and evidence checks.
- `GlobalWorkspaceFrame`: current globally visible context with source lineage and expiry.
- `LocalProcessorInbox`: specialized lanes receive broadcast frames relevant to them.
- `ConsciousnessClaimBlocker`: prevents unsupported language that broadcast routing creates consciousness.

## Promotion Gates

- Trace why each signal entered the global workspace.
- Expire broadcast frames to prevent stale global context.
- Keep private information scoped even when globally salient.
- Test missed-critical-signal and noisy-broadcast failure modes.
- Do not use consciousness labels in product claims.

## Risks

- Global broadcast can leak private or irrelevant state across lanes.
- Salience models can prioritize drama over usefulness.
- Theories of consciousness remain contested and should not be treated as implementation proof.
